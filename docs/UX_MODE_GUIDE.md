# Mode Guide

## Core Lenses

- `overview`: quick inventory and readable context.
- `debug`: full content, line anchors, risks, and detailed diagnostics.
- `architecture`: signatures, dependencies, and structural signals.
- `obsidian`: Markdown headings, frontmatter, wikilinks, tags, and tasks.

## Domains

- `code`: development, tests, dependencies, and contract drift.
- `documents`: HTML structure plus PDF/EPUB metadata and citation ledgers.
- `research`: term, method, inference, provenance-hint, and gap-question reports.
- `modeling`: equation, variable, parameter, assumption, and audit candidates.
- `creative`: media ledgers and script-target candidates without perceptual claims.
- `mixed`: emits all applicable deterministic subpacks.

## Source State

- working folder: current filesystem contents.
- Git HEAD/ref: temporary revision snapshot.
- changed: unstaged and modified files.
- staged: files staged for the next commit.

Use `--profile post` for automatic orientation. Use `--domain` and `--lens` to
override a recommendation.
