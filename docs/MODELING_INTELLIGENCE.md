# Modeling Intelligence

Modeling analysis extracts candidates from text, code, LaTeX, and notebooks.
It does not execute models, solve equations, validate units, or prove that a
model is correct.

Current pack files:

- `MODELING/MODELING_ORIENTATION.md`
- `MODELING/EQUATION_CANDIDATES.md`
- `MODELING/VARIABLE_CANDIDATES.md`
- `MODELING/ASSUMPTION_MARKERS.md`
- `MODELING/PARAMETER_CANDIDATES.md`

Audits look for deterministic vocabulary associated with thermal, economics,
statistics, optimization, and simulation work, then report missing-context
markers.
