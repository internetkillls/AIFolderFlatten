# Creative Reference

Creative mode is an asset-ledger and handoff system, not a perceptual media
analyzer.

Current pack files:

- `CREATIVE/CREATIVE_ASSET_LEDGER.md`
- `CREATIVE/MEDIA_LEDGER.md`
- `CREATIVE/SCRIPT_TARGET_CANDIDATES.md`

The core records paths, extensions, sizes, hashes, and deterministic format
affordances. It does not infer visual style, audio mood, motion, BPM, scene
content, or artistic meaning. Media is never base64 embedded.
